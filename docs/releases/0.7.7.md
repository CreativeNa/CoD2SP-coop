## What changed since 0.7.4

- The partner's tank shot: the yellow sand cloud over the turret is gone, the muzzle flash and smoke are at the barrel.
- Pistol-ready animation slots for the partner, a guard against reload spam, a version line in the menu, more translated menu texts.
- Script diagnostics are no longer printed on the screen (set `coop_debug 1` to see them).
- Ctrl+V pastes an IP address from the clipboard into the host address field of the CO-OP screen.
- Mission progress flags (the script's own marks such as `player_entered_backyard`) are mirrored between the two players by default; `seta coop_flags "off"` switches the sending off.
- Fixed: the partner could stand in a T-pose on some missions (the animation tree of the partner exceeded the engine limit); the crouch and prone pistol clips now use the rifle poses.
- Fixed: the version line in the CO-OP screen was drawn twice.
- Checkpoints belong to the host: the second player sends none and takes every checkpoint of the host. After the death of either player both return to the host's latest checkpoint, not to the start of the mission.
- Scene and objective triggers can be mirrored (`seta coop_triggers "on"` on both PCs): what one player starts happens for the other too. A trigger waits while the other player is more than 1500 units away; triggers that spawn allies and the pipe/trench entry of `trainyard` are left to the player's own entry.
- Fixed: mission flags whose name contains a space (for example `reached warehouse`) were cut and never arrived.
- **F7** (second player) loads the host's latest checkpoint; the host then sends again the scene triggers it fired after that checkpoint. A second press within 6 seconds is ignored.
- The partner health read-out next to the compass is removed for now.
- Diagnostics of the script go to `coop5.log` instead of the screen.
- The installer also accepts one more build of `CoD2SP_s.exe` reported by a player (not tested by us; it prints a notice).
- `coop5.log` now records which build of `CoD2SP_s.exe` the game runs (size and CRC-32) and whether it is a build we know.
- Fixed: the version line in the CO-OP screen showed `dev` after a first install.
- `coop_net.csv` in the game folder no longer grows without limit (about 4 MB per game start; an older, larger file is started again).
- Trigger mirror: scenes that rely on characters of the other player's area (for example in "Comrade Sniper") are left to the player's own entry; this removes a flood of script errors on the second PC and lets the objectives advance.
- A flag received from the partner that does not take effect at once is now reported in `coop5.log` (waits because the other player is far away / unknown here / dropped / already set).
