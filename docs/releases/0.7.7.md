# Call of Duty 2 Co-op — 0.7.7

Unofficial free modification. Not affiliated with the publisher or developers of the game.
Needs your own copy of the game: the installer builds the mod from **your** game files; nothing of the game is in this package.

## Requirements

- Call of Duty 2 single player **1.3** (Steam or retail).
- Windows 10/11 with PowerShell 5.1. Radmin VPN (recommended) or one local network. Ports UDP 27201–27202, TCP 27203.

## Installation

1. Close the game, unpack the zip, run **`CoD2Coop.exe`** → **1) Install the mod**.
2. Start the game through Steam: the main menu has a **CO-OP** button. **Uninstall** is in the same menu.

## How to start

1. **Host** — CO-OP → HOST, then a **new** mission.
2. **Guest** — CO-OP → JOIN (`auto`). The guest's game opens the same mission by itself.

Details: [docs/HOW_TO_PLAY.md](../HOW_TO_PLAY.md). Two-PC test: [TWO_PC_TEST.md](../TWO_PC_TEST.md).

## What is in this build

- Link and automatic mission follow (also from a briefing: the guest starts the mission that follows it at once; the host's difficulty is applied on the guest).
- The partner as a soldier of your campaign: stand, run, crouch, crawl, jump, melee, shoot, reload, throw grenades (frag, smoke, the potato), with or without a weapon.
- Kills of enemies, optional mission-flag mirror, death of either player → shared checkpoint (the host's checkpoint files are copied to the guest).
- **Start barrier**: both PCs wait for each other at the start of every mission (a panel is shown, 20 s at most).
- **Tanks** on `libya` and `88ridge`: the guest is seated in a second player tank, the partner's tank is shown as a model that follows and fires.
- Menu in six languages, borderless window, RAW mouse input, **F8** to the partner, the partner's health next to the compass.
- Logs: `CoD2Coop.exe logs`; automatic rotation of `coop5.log`; crash and hang reports.
